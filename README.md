# My-second-project
Мой второй проект я собираюсь написать на С++. Основная задумка: пользователь в консоли ведёт учёт книг в библиотеке. Программа хранит список книг, позволяет добавлять, искать, выдавать читателю и возвращать обратно, удалять, и при каждой операции проверять особые случаи, а не просто выполнять действия. Если пользователь введёт ISBN книги, которой нет в библиотеке, или попробует выдать книгу, которая уже выдана, программа выведет понятное сообщение в консоль, а не упадёт и не сделает что-то неверное.
Использовать программа будет структуру Book для хранения данных об этой книге (название, автор, год, ISBN, статус, кому выдана) и vector<Book> как хранилище всех книг. Все операции отдельные функции: addBook, showALLBooks, findBook, issueBook, returnBook, removeBook. Метод хранения может поменяться в процессе углубления в материал например, на map<string, Book> с ключом по ISBN для быстрого поиска, но для первой версии vector достаточно, потому что так проще отлаживать.
Для начала я напишу программу, которая запрашивает у пользователя в консоли данные о книге, добавляет её в vector, показывает все книги и позволяет найти книгу по названию, автора или ISBN. В случае, если книга не найдена, если ISBN уже существует или если библиотека пуста, программа выводит соответствующее сообщение.
